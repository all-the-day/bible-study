# 书报纲目策展流水线（book-outline playbook）

> 2026-11-01 建立。第一批：《倪柝声文集》第一辑「灵修指微」+「十字架的道」共 55 章。
> 本文是**可套用的工作方法**；功能全景见 `docs/FEATURES.md`，工程约束见 `AGENTS.md`。

## 1. 这是什么

给书报模块的每一章整理一份**纲目**（章节标题清单 + 层级），用途与生命读经右栏「纲目」tab 相同：
点击跳转、滚动高亮，并通过「哪些行算标题」同时纠正正文里标题行的加粗范围
（现在 `detectLrHeading` 运行时正则会把经文引用行、页码噪声也加粗）。

**为什么必须一批一批人工（LLM）策展**：书报正文是早年印刷品爬取来的，没有结构标记，
内部标题就是「裸短行」，与正文短句、经文引用行、页码、目录行混在一起。
全库实测（倪文集 1325 章）：268 章零识别、631 章只有 0–4 个标题、另有单章 887 个误报
（读经计划表）——规则调参无法覆盖，只能逐章读原文判定。

## 2. 流水线与数据契约

```
scripts/outline-src/{系列}.json     人工/LLM 逐章策展（入库、唯一事实源）
        │  每批一个工单脚本（行号决策 → 抽取精确文本 emit，见 §5）
        ▼
scripts/build-book-outlines.py      对照已导出正文逐条校验（文本必须整行存在且按文档顺序）
        ▼
data/books/outline/{系列}-{辑}.json 生成产物（不入库；deploy.mjs 同步整个 data/ 自动带上；
                                    APK 需在 build-apk.yml 数据清单单独加）
```

- **键的基数**（与标注 loc、`numbers.json` 一致）：策展源 `"辑:书:章"`，辑 1 基、书 0 基、章 0 基；
  产物按辑分文件、键 `"书:章"`。
- **条目两种形态**：
  - `{"t": "整行文本", "l": 1}` —— 精确匹配，该行必须整行等于 `t`；
  - `{"p": "行首前缀", "l": 2, "label": "显示名"}` —— 前缀匹配，用于「标题+正文」挤在同一行的合行
    （如第十七篇肆底下的一~十），`label` 是去掉正文后的显示名。
- **章级三态**：有条目 = 策展纲目（同时取代该章运行时识别）；
  `[]` = 已审阅且确无纲目（**并压制该章 `detectLrHeading` 误报**，如读经计划表章）；
  键缺失 = 未策展（前端回退 `detectLrHeading`，即改造前行为）。
- **层级 1–4**（语义层级，非格式层级）：1=篇内主级、2=次级、3=三级、4=极少数深层。
  与样式类的映射：`lr-toc-l{1..4}`（纲目缩进）、`bk-head lr-h{1..4}`（正文标题字号）。

## 4. 层级与「该不该入」的判定顺序

1. 整行是一个**标题**（名词性短语/设问/编号项），引领下文 → 入；层级看它在本文的实际嵌套
   （壹>一、（附）与壹同级、「参」是壹的兄弟——**别看格式看语义**）。
2. 整行主体是**一段经文引用加出处** → 不入（除非带语义标签，见形态表第 7 行）。
3. 整行是**元数据/噪声**（日期、页码、署名、全文完）→ 不入。
4. 拿不准的：**宁可不入**。纲目可以后补，错链（点了跳错地方）没有自愈手段。

## 5. 批次工作流（每批照此执行）

### 5.1 第一批（样板，手工）

1. **定批次粒度**：一「本」为一批（倪文集 62 本；第一辑两本 = 第一批 55 章）。
2. **导出信号行**：把该本每章的 `content` 逐行打出，标注行号、字数、`detectLrHeading` 识别结果；
   只细看 ≤34 字的行和识别命中的行，长句是正文不用看。
3. **写工单**：复制 `scripts/outline-src/_worklist_ni_batch1.py` 改成本批决策
   （`(辑,书,章) -> [(行号, 层级)]`，合行加 `'P'`；确无纲目的章进 `EMPTY`）。
   **用行号不用文本**——从数据里抽精确文本，杜绝全角空格/引号抄错。
4. **跑工单** emit `scripts/outline-src/ni.json`，再跑
   `python scripts/build-book-outlines.py ni`。校验失败会打印找不到的行——回去修行号。
5. **QC**（每批必做）：
   - 有纲目的章逐章过一眼纲目文本（`python -c` 读产物即可）；
   - 显式空的章确认真的是目录/表格/无标题章，不是漏策展；
   - 统计：每本平均条数、零纲目章数、最长条目（>60 字的条目考虑是否该用 `label` 截断显示）。

### 5.2 第二批起（草案 + 人工复核，主力模式）

手工读完全库不现实。`_draft_books.py` 把 §3/§4 的判定固化成机械规则，人只处理标记项：

```bash
python scripts/outline-src/_draft_books.py gospel 1 --all            # 福音类 70 本
python scripts/outline-src/_draft_books.py ni 1 2-19 --force         # 规则改进后重跑覆盖
python scripts/build-book-outlines.py gospel                         # 校验 + 产出
```

- **保留**：编号标题（壹/**参**/一/１/（一），层级按实际嵌套）、裸短行标题、带「─」语义标签的小标题、
  诗歌编译栏「标题（全角空格填补）+ 译」的译名行（按前缀收）。
- **剔除**：经文引用行（引文+卷章、无「─」标签）、页码残片（`N02xx`/纯数字/裸数字字）、
  日期署名（阿拉伯与**中文数字**年月日、客中/脱稿/谨识/敬上/谨启/旅次收尾）、
  **作者落款**（≤20 字且含「倪柝声/柝声」）、全文完、读经：、与章名/书名重复的行。
- **诗歌类（2026-11-02 按 gospel/歌中的歌 实测新增）**：
  - 诗歌块元数据（编号/节拍「15 15 15 6副（英1017）」/调号「降B大调 4/4」/类目「福音─生命」）；
  - 「诗歌」标签起的诗歌块内，长编号行是诗节（`一 基督已经穿上人性，…`）→ 剔；
  - **诗句/引文条目**：编号行以句读收尾（，；！。、：？）且非「标题　正文」合行 → 剔。
    **逗号收尾不受长度下限保护**——标题不会以逗号收尾（诗句折行、目录残行）；
  - **诗歌合集章整章显式空**：章名「分类N…」或章内 `第N首`/`笫N首` 行 ≥5
    （倪文集《歌中的歌》15 个分类章）——节次行不是标题，稀疏的第N首也不成导航。
  - **版块/目录标签行**：`纲目`/`目录`（13 个系列共 801 处，只标记「以下是目录」）、
    periodicals 晨兴模板三件套 `一 重点经节：`/`二 你喜欢的经节：、、。`/`三 真理要点：`（共 1999 处）、
    转录稿标记 `读经:`/`祷告:`/`见证:`（带冒号形态；结晶读经等 82% 是录音转录稿）、网页残留 `阅读更多＞`。
    **裸「祷告」「见证」不算标签**——它们常是真小节标题（「信心/祷告/奉献」并列），
    只有下一行是祈祷文/署名（`主阿|主啊|求你|我们祷告|阿们|弟兄…`）时才当标记剔。
  - **纯西文行 / 私有区字符行**：荒漠甘泉的英文署名残字（`School`、`Times)`）、
    福音天地网页装饰图标 ``（浏览器渲染成空白，不滤会在纲目里出现空条目）。
  - **系列级校准 `SERIES_LONG_TITLE`**：十二篮的节标题普遍 13–20 字（「抹大拉的马利亚对于主的认识」），
    超出 `detectLrHeading` 的 12 字上限；仅对该系列开放「纯中文短语 + 下一行是长段落」补收
    （圣经疑难等系列的同类形态是正文句子，不开口子）。
  - **块标签「读经」/「诗歌」不入纲目**（只作版块标记，不入 TOC）；**表格/重复字符残片**
    （`┌─────┘`、`第第第第第`）剔除；**命中行 >60 字转前缀匹配 + 截断显示名**
    （否则整段正文被刷进纲目列）。
  - **「─」豁免**：带「─」引出正文的列表式小节（`一　个人生活方面─要学…。`）是标题，
    不受「句读收尾 → 判诗句」规则约束（否则鼓岭训练简介那类章会整片漏收）。
- **层级**：编号类按格式（壹/参=1，一/１=2）；（一）类与裸短行跟随前一标题封顶 3，
  **连续裸短行保持平级**（不逐级递增），遇编号标题重新计数。
- **合行**：>24 字的编号行按「标题　正文」拆成前缀匹配（`p` + `label`）。
- **零识别章** → 显式空（已审阅）；正文漂移由 `build-book-outlines.py` 校验兜底。
- **报告里的 FLAG 行必须人工过**：`>30 处识别`（目录/表格章？福音故事的编号小标题会误触发，看一章即可）、
  `─ 标签行`（层级是推测）、`合行`（label 拆得对不对）、`零识别但有可疑短行`（多数是日期/译名误报）。
- 已知可接受残留（用户定调「大部分可以就行」）：产物里明显非标题的条目约 0.55%
  （句读开头/无中文），集中在 fuyintiandi 3.6%、kdyf 3.6%（希腊文转写）、hmgq；
  期刊期号章的句子碎片；引号收尾的个别诗节；福音见证里夹诗的长条目；
  结晶读经等转录稿的零散口语碎片（jd 无编号条目 949 条里约 164 条是「第N篇」章标题、117 条含句读）；
  倪文集《灵修指微》第十八篇「附灵战原理撮要」的句子式条目（第一批手工策展，人工保留）。
- **整章无内部标题的叙事体/诗歌集不做纲目**（用户 2026-11-02 定调，《天路历程》即此类：
  23 章纯叙事+脚注号，识别项全是噪声——跳过，不建策展文件；若哪天想清掉正文里
  被误加粗的脚注号，再补一份全 `[]` 即可）。

## 6. 已知坑（第一批实测）

- **`detectLrHeading` 的「参」bug**：壹/贰 在 level-1 类里，但「参」（叁的俗写）不在，
  「参　胜过撒但」被当成裸短行 level 0。草案器已本地绕过（识别类补「参」）；
  **建议后续在 app.js 的类里补「参」及常见俗写**（改渲染器前先跑 theme/lr 相关测试）。
- **12 字上限**漏掉 13–20 字的真标题（设问句、带引号的短语），见形态表第 3 行。
- **标点收尾**（。？！：）一律不识别，但引导性小标题经常以冒号/句号收尾。
- **合行**（标题和正文同一行）正则必然整行加粗；策展用 `p`+`label` 只把它收进纲目，
  正文加粗范围不变（要修得改渲染器拆行，暂不做）。
- **索引稳定**：纲目按 (辑,书,章) 定位 + 文本匹配，**不碰正文、不碰标注坐标**；
  正文若因导出清洗变化，构建脚本会报「找不到整行」而不是静默错位。
- **运行时游标卡死**：若某章正文漂移导致策展条目匹配不上，前端实现应允许
  「当前条不匹配但下一条匹配当前行时跳过卡住条」（resync），避免后半程纲目全丢。

## 7. 前端消费（2026-11-02 已实施）

书报阅读器右栏已有「纲目」tab（默认），与生命读经右栏同构、复用同一套 CSS 类：

- `renderBookSide`：`纲目 | 笔记` 分段（`state.bookSideTab`，默认 outline，纯内存不持久化）；
- `ensureBookOutline(series, volume)`：懒加载 `data/books/outline/{series}-{辑}.json`，
  404/失败按「本辑未策展」缓存空表（整辑回退识别，不重复请求）；`bookOutlineFor()` 取本章
  （数组=已策展、`[]`=显式压制、null=未策展）；
- `renderBookContent` 新增 `outline`/`idPrefix` 参数：有策展数据时**完全取代**
  `detectLrHeading`（指针顺序游走，当前条失配时允许前跳自愈），标题 div 得
  `id = bkh-{辑}-{书}-{章}-{序号}`；无数据回退原识别；
- `renderBookOutline`：条目 `l`/`t`/`p`/`label` 渲染 `.lr-toc-item` + `bindLrOutlineSpy`
  滚动高亮（与 lr 共用 `_lrSpy` 句柄，books 模块 `onLeave` 负责解绑）；
- **预热**：书报模块 `enter()` 里 `await ensureBookOutline(...)`——`enterModule` 的
  renderMain/renderSide 是 `Promise.all` 并发，不预热右栏会早于懒加载完成而回退成识别结果
  （2026-11-02 深链实测竞态，回归见 book-reader-test 第 9 步）。
- **单一来源（CR 2026-11-02 修）**：`collectBookHeadings(content, 章名, 书名, outline)` 是正文加粗行与
  TOC 的**唯一**判定入口（含开头书名/章名行的跳过逻辑）。旧实现两侧各算一遍——正文按实际命中计数、
  TOC 按数组下标，回退路径混进被跳过的开头行后**整体偏一位**（实测 bio 等未策展系列 163 章点了跳错标题）。
  今后任何改标题判定/跳过的改动都只动这个函数。
- **默认 tab**：本章没有条目时默认落「笔记」（未策展系列否则一进阅读器就是空态）；
  用户点过任一 tab 即 `state.bookSideTabPinned = true`，不再自动切。
- **产物写入**：构建脚本原子写（tmp + `os.replace`），并发测试不会读到半个 JSON；
  某系列校验失败会**删除该系列旧产物**——否则 deploy.mjs 会把上一次的纲目静默发出去。
- 移动端：书报模块右栏本就抽屉延后，纲目 tab 随右栏一起桌面可见，无额外适配。

**上线前待办**：`build-apk.yml` 数据清单加 `data/books/outline/*`；`sw.js` 的 `/data/*`
stale-while-revalidate 已覆盖；`AGENTS.md` 文件结构表补脚本与数据目录；发布时写 `CHANGELOG`。
