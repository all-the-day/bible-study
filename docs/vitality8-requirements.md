## 需求要点（2026-10-21，用户补充）

专题学习有**作业单**，每周的结构是：

1. **三篇生命读经（按顺序）**
2. **指定书报一篇**
3. **背经任务**
4. **所学章节的注释读两遍**
（加原来的：该章圣经原文）

例：「本周学腓立比一章」= 一个任务 = 一章。
作业单原文不在本项目数据里（已核实：书报库里的《新约圣经恢复本读经指引》不是它），内容由本文件定。

## 已定形状

- 形态 = **任务清单（todo list）**：链接聚合 + 完成勾选，不嵌正文，全部深链跳转（复用 hash 路由）
- 顺序 = 腓 1→4、西 1→4，无主题分组（「八条线」导语废弃）
- 每个任务 = 一章，任务内子项：
  | 子项 | 形态 | 跳转 |
  |---|---|---|
  | 读原文 | 链接 | `#/bible/{卷}/{章}` |
  | 生命读经 ×3（按顺序） | 链接 ×3 | `#/lr/{卷}/{篇}` |
  | 指定书报 ×1 | 链接（**内容待填**） | `#/book/{系列}/{辑}/{书}/{章}` |
  | 背经 | 勾选 + 经节（**经节待填**） | 链接到该章 |
  | 注释读两遍 | 两个勾选 | 链接到该章（注解在读经模块研读列） |
- 顶部显示「已完成 n/8」进度；每任务一个笔记框（复用现有屏级笔记与云同步）
- 专题内划线（`type=topic`）随「不嵌正文」一并下线

## 待你确认（4 项）

1. **8 个任务 = 8 章按序**，对吗？（作业单若只覆盖部分章、或一周跨多章，说一声）
2. **三篇的选法**：默认「整段落在该章内 + 按篇号前三篇」。若你的作业单是指定篇号，把 8 行的篇号直接改掉；
   西 4 只有 2 篇，第三篇怎么补（并入第 30 篇？本周就读两篇？）
3. **指定书报清单**：8 行各要哪篇（系列·书名·章名）？没有就先留空位，后续再填
4. **背经经节**：每周背哪节？没有留空；也可以让我用《读经指引》里各周「祷读经节」预填（那不是作业单，只是默认值）
