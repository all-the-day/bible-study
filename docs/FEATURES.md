# bible-study 功能文档

> 基于 v1.0.52 代码梳理（2026-10-16）。工程约定、部署与测试流程见 [AGENTS.md](../AGENTS.md)。
> 单页应用，原生 JS 零框架；主入口 `app.js`（约 6500 行）+ `sync.js` + `update.js` + `sw.js`。

## 一、阅读模块（统一阅读器外壳）

应用 = 首页（合集块网格）+ 五个模块，共用三列阅读器外壳（顶栏 / 正文列 / 研读列）。
模块切换只在首页进行；`body-mod-*` 类控制各模块容器显隐。

### 1. 读经（bible）

- **正文**：恢复本经文，含章纲目（壹/贰/…层级）、注脚（`注N` 点击弹窗）、串珠（字母标记弹经文串）
- **研读列**（右栏）三个 tab：
  - **注解**：本章全部标注（经文划线 + 生命读经划线聚合）
  - **生命读经**：本章匹配的篇目正文（按 `lrMap` 手动映射优先、`autoMatch` 自动匹配兜底）
  - **我的笔记**：章级笔记 + 本章划线汇总
- **研读全屏**（`studyFullBtn`）：正文区切换为「纲目侧栏 + 正文」双栏（`lr-full-wrap`），窄屏自动隐藏纲目列

### 2. 生命读经（lifereading）

- **主区**：当前书卷的篇目正文，经文引用自动包裹（见第四节）
- **研读侧栏**：`纲目 | 笔记` 两 tab
  - 纲目：全篇 10 级标题树（壹/一/１/ａ/（一）/…共 10 级），点击滚动定位 + scroll-spy 高亮
  - 笔记：篇级笔记 + 本篇划线汇总
- 篇目数据按卷懒加载（`lrVolumes` 缓存），跨书卷篇目跳转自动选书

### 3. 倪文集 / 书报（books，双入口）

- 首页拆两个入口：**倪文集**直达倪柝声文集；**书报**进二级合集层（合集块网格，数据驱动自动渲染，点块进入对应系列）
- **多系列**架构（当前 32 个系列：倪柝声文集 3 辑 62 本 1325 章；十二篮 12 辑 144 篇；传记与文集 41 本 902 章；福音天地 22 本 845 章；ezoe 福音类 70 本 / 读经类 28 本 / 代售与期刊类 32 本 / 其他 8 本 / 造就类 2 卷 232 本 / 教会与事奉类 96 本；以及 2026-10-19 接入的 22 个灵粮系列——属灵书报 4 辑 224 本 2425 章、特会信息 37 本、结晶读经 29 本、新约总论 8 册、圣经之旅 15 册、真理课程 8 卷、生命课程 4 卷、圣经要道 6 卷、圣经疑难、健康话语的规范、真理专题、真理的辨正、肯定与否定、解剖毒瘤、召会历史、天路历程、希伯来民族简史、荒漠甘泉 365 日、造就故事、拾零、职事信息、成全训练信息）
- **主区**：书 → 章正文（纯段落排版）
- **研读侧栏**：本章笔记（章级领受 textarea + 本章划线汇总）；章切换统一走目录抽屉（原「章列表」tab 与抽屉冗余，v1.0.38 后删除）
- 书报合集层顶部搜索：合集名 / 跨合集篇目直达

### 4. 听抄（morning）

- **主区**：特会期 → 篇正文（逐段渲染，经文引用检测带跨行书卷上下文）
- **研读侧栏**：笔记汇总

### 5. 笔记管理（notes）

- 三列：分类树（左）/ 条目列表（中）/ 编辑面板（右；移动端编辑走全屏 push + 返回条）
- **列表能力**：来源 tab（全部/经文/生命读经/书报/听抄）、颜色筛选、全文搜索、分组（按书卷/期）、排序（书卷序/时间倒序）、批量选择/删除
- 点击条目 = 模块内选中进编辑面板（不跳转原文）；编辑面板支持改色 / 改笔记 / 删除 / 定位跳转

## 二、统一导航抽屉（#navDrawer，四阅读模块共用）

- **双栏主从浏览**：按模块渲染层级一/层级二列表（层级一不带序号）
  - 读经：书卷（底部旧约/新约切换，随当前书卷同步）→ 章
  - 生命读经：书卷 → 篇目（懒加载，保留「第N篇」篇目编号）
  - 书报：书（或扁平系列如十二篮的「辑」，底部辑切换仅非扁平系列）→ 篇/章；左栏不带序号与篇数副标，右栏标题剥掉与正文重复的「第N篇/一/（一）」序号
  - 听抄：期 → 篇
- **当前位置高亮同步**：任意跳转（抽屉内/搜索/历史/引用点击）后停靠列 `cur` 高亮跟随
- **Segment**：浏览 | 历史
  - 历史：跨模块阅读历史（上限 50 条、同位置去重置顶、可清空；首页「最近阅读」展示最近 5 条）
- **模块级搜索**：读经搜书卷、其余模块搜全量篇目/章节（seq 竞态守卫防慢请求回写）
- 桌面停靠常驻（☰ 收起/展开）；移动端浮层（遮罩 + 平移，crumb 点击唤出）
- **不承载抽屉的态**：首页、书报二级合集层（层级选择页，均隐藏 ☰）；桌面笔记管理（分类树常驻左栏，隐藏 ☰；移动端仍靠 ☰ 唤出分类树）

## 三、标注与笔记

- **5 色语义划线**（沿用 bible-reader 配色）：选中文本弹浮动工具条，点色即存
- **笔记**：划线可附笔记（模态编辑器，展示标注原文预览）；标注支持改色 / 改笔记 / 删除（分离操作语义）
- **重读**（各阅读器划线汇总标题旁）：当前章/篇存在无笔记的划线时显示「重读」——一键清掉**当前阅读单元自己的**无笔记划线（读经模块只清本章经文，关联生命读经篇目属于别的「篇」不动；生命读经=本篇；书报=当前章；听抄=当前篇），**带笔记的标注原样保留**；确认框明示条数与保留数，删除同步到云端、不可撤销
- **笔记数据五类**：经文标注（annotations，数组）、章级笔记、生命读经笔记、书报笔记、听抄笔记（kv）
- **复制带出处**：复制标注/正文时附引用出处，方便反馈 bug
- 笔记管理模块承担全部标注的浏览/检索/编辑（见第一节 5）

## 四、经文引用引擎（ref-link）

正文（经文纲目/生命读经/书报/听抄）中的经文引用自动检测并包裹为可点击 `ref-link`：

- **识别形态**：全书式（约一14）、相对式（二五11 / 三9上 / 33）、章节式（三章十九节）、
  列举式（一、二节 / 和 / 与）、范围式（15～17 / 至）、跨章范围（十章二十八节至十二章二十四节）、
  上下半节范围（启一4下～5上）、引导词（参/见/参看）
- **跨行书卷上下文（carry）**：听抄逐行渲染时段首省略书卷的引用（如「四24」）沿用上一行书卷
- **正文书卷弱上下文**：行文里不带节号的「全名书名」（如「哥林多后书」「希伯来书」）与「书卷+章」
  （如「罗马八章」）虽不成引用，但为其后同一句内的引用提供书卷/章号归属——「尤其是哥林多后书，
  多处提到耶稣的治死（四10～13）」「罗马八章所说的万有（28）」都能正确落到林后 4:10-13、罗 8:28；
  旁及别卷不跨句（提及在前一句、引用在后一句仍是行文旁及，归主题书卷），人名简称（约书亚/撒迦利亚等）不建上下文
- **守卫**：章数越界过滤（防「但=but」误判书卷）、节存在性校验（bibleText 未加载时跳过、重渲染后生效）、
  列举不跨章吞并、纯数字右边界防误匹配（1920年/25章）
- **点击**：弹经文卡（逐节展开；半节引用数据未拆分时回退整节）

### 人物链接（person-link，原型：十二篮 + 倪文集）

- 正文里的人名（如「慕迪」「司布真先生」「路德马丁」）自动识别为青绿点线可点，与经文的紫色虚线区分
- **点击弹人物小传**：简介 + 英文名·生卒 + 小传摘录（约 150 字）+ 出处，可「查看完整小传 ›」跳到书报·传记与文集对应章
- **当前覆盖范围**：**十二篮 + 倪柝声文集**正文启用（数据 `data/persons.json` 的 `scope`），其余模块/系列不受影响；词典收录使徒时代之后的历史人物（使徒时代人物名与圣经书卷简称冲突，排除）

## 五、账号与云同步

- **账号密码登录**（主入口）：设置内输入账号名+密码启用同步（账号由管理员开通）；换域名/新设备不再需要授权码。授权码兑换保留为折叠次入口（管理面板 `duoban.xyz/bible-api/admin` 生成/管理）；默认纯本地，未启用时完全离线
- **条目级同步**：标注与四类笔记逐条同步，本地存储格式不变
- **冲突不丢数据**：多端并发编辑自动裁决，败者全文进冲突备份
- **手动同步三件套**（设置内）：立即同步 / 数据对比（本机↔云端）/ 强制推/拉
- 离线可用：断网时改动排队，恢复后自动补传

## 六、阅读体验

- **排版面板（Aa）**：字号 85–200%、行距，桌面居中弹层 / 移动端底部 sheet，按模块独立记忆基准
- **阅读主题**（设置内）：**经典**（默认，靛蓝渐变顶栏）/ **靛蓝**（实色顶栏、中性微影）/ **暖纸**（纸色底+墨色字，经文去卡片化、节间细分隔，暖赭强调）/ **素灰**（中性灰分层、顶栏融入背景、单一强调色）。纯本地偏好不入云同步，刷新不闪变；首页与书报合集块图标随主题在 emoji 与线性图标间切换；标注 5 色语义与排版（Aa）设置各主题通用
- **隐藏注号**开关（设置内）
- **使用帮助**（设置内）：「其他」组的帮助入口——四项功能介绍（起点/阅读/划线笔记/实用技巧，含五色标注语义说明）+「最近更新」；更新弹窗发现新版本时展示同一来源（app.js CHANGELOG）的用户语言「本次更新」，并可跳转帮助查看
- **阅读进度条**：正文滚动实时指示（#textCol 唯一滚动容器）；进度线在顶栏内、视觉仍位于顶边，iOS 顶部不再被进度线取色影响（经典主题白线可见）
- **视图模式**（桌面读经模块）：双页 / 上下 / 全屏
- **移动端单视图**：顶栏 `读经|研读` pill，跨模块进入时高亮自动对齐实际视图
- **分栏拖拽**：桌面研读列宽度可拖（resize-handle）
- **滑动翻页**（移动端）：正文快速横扫切章/篇——向左=下一篇、向右=上一篇（读经切章、生命读经/听抄切篇、书报切本书内章，到边界不动）；与划线标注互不干扰，弹窗/抽屉打开时不响应
- **网址与分享（路由）**：每个位置都有独立网址（首页无 hash；`#/bible/卷/章`、`#/lr/卷/篇`、`#/book/系列/辑/书/章`、`#/morning/期/篇`、`#/notes`、合集层 `#/hub`）；链接可直接分享直达，刷新保持位置；翻章/翻篇不留历史记录，后退一步回上一级（换书/换模块/回首页可逐级后退）
- **返回键（APK）**：先关弹窗/抽屉，再逐级后退；首页（无可后退）按返回退出应用；与浏览器后退/前进行为一致

## 七、首页

- **首屏 splash**：启动即显示（含随机经节），启动数据下载期间显示真实字节进度（首次访问慢网约半分钟可感知、可重试；二次访问有缓存秒过）
- 合集块网格：读经/生命读经/我的笔记/听抄/书报
- 顶部搜索：书卷章（如「创24」）/ 生命读经篇目 / 笔记，直达原文
- 最近阅读：最近 5 条（无历史整块隐藏），「全部 ›」弹出全部历史（首页就地浏览，点条目跳原文）
