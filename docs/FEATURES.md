# bible-study 功能文档

> 基于 v1.0.64 代码梳理（2026-10-26）。工程约定、部署与测试流程见 [AGENTS.md](../AGENTS.md)。
> 单页应用，原生 JS 零框架；主入口 `app.js`（约 8300 行）+ `sync.js` + `update.js` + `sw.js`。

## 一、阅读模块（统一阅读器外壳）

应用 = 首页（合集块网格）+ 六个模块，共用阅读器外壳（顶栏 / 正文列 / 研读列；听书为单列）。
模块切换只在首页进行；`body-mod-*` 类控制各模块容器显隐。

### 1. 读经（bible）

- **正文**：恢复本经文，含章纲目（壹/贰/…层级）、注脚（`注N` 点击弹窗）、串珠（字母标记弹经文串）
- **研读列**（右栏）三个 tab：
  - **注解**：本章全部标注（经文划线 + 生命读经划线聚合）
  - **生命读经**：本章匹配的篇目正文（按 `lrMap` 手动映射优先、`autoMatch` 自动匹配兜底）；顶部「指定篇目」弹窗列出本卷全部篇目并预勾当前生效的篇目，**打开即滚到第一个勾选项**
  - **我的笔记**：章级笔记 + 本章划线汇总
- **研读全屏**（`studyFullBtn`）：正文区切换为「纲目侧栏 + 正文」双栏（`lr-full-wrap`），窄屏自动隐藏纲目列

### 2. 生命读经（lifereading）

- **主区**：当前书卷的篇目正文，经文引用自动包裹（见第四节）
- **研读侧栏**：`纲目 | 笔记` 两 tab
  - 纲目：全篇 10 级标题树（壹/一/１/ａ/（一）/…共 10 级），点击滚动定位 + scroll-spy 高亮
  - 笔记：篇级笔记 + 本篇划线汇总
- 篇目数据按卷懒加载（`lrVolumes` 缓存），跨书卷篇目跳转自动选书

### 3. 倪文集 / 书报（books，双入口）

- 首页拆两个入口：**倪文集**直达倪柝声文集；**书报**进二级合集层（合集块网格，数据驱动自动渲染，点块进入对应系列）
- **多系列**架构（当前 32 个系列，书报模块内搜索与首页检索均覆盖全部系列：倪柝声文集 3 辑 62 本 1325 章；十二篮 12 辑 144 篇；传记与文集 41 本 902 章；福音天地 22 本 845 章；ezoe 福音类 70 本 / 读经类 28 本 / 代售与期刊类 32 本 / 其他 8 本 / 造就类 2 卷 232 本 / 教会与事奉类 96 本；以及 2026-10-19 接入的 22 个灵粮系列——属灵书报 4 辑 224 本 2425 章、特会信息 37 本、结晶读经 29 本、新约总论 8 册、圣经之旅 15 册、真理课程 8 卷、生命课程 4 卷、圣经要道 6 卷、圣经疑难、健康话语的规范、真理专题、真理的辨正、肯定与否定、解剖毒瘤、召会历史、天路历程、希伯来民族简史、荒漠甘泉 365 日、造就故事、拾零、职事信息、成全训练信息）
- **主区**：书 → 章正文（纯段落排版）
- **研读侧栏**：本章笔记（章级领受 textarea + 本章划线汇总）；章切换统一走目录抽屉（原「章列表」tab 与抽屉冗余，v1.0.38 后删除）
- 书报合集层顶部搜索：跨全部系列搜书名 / 篇目 / 书号（书号如 `1001` 精确命中），命中词高亮、显示真实总数

### 4. 听抄（morning）

- **主区**：特会期 → 篇正文（逐段渲染，经文引用检测带跨行书卷上下文）
- **研读侧栏**：笔记汇总

### 5. 听书（audio）

- **主区（单列）**：讲次标题 + 播放器（进度条可拖动定位、±15 秒、倍速 1×/1.25×/1.5×/2×/0.75×）+ 分段列表
- **进度条**：多段讲次上方标「第 N 段 · 共 N 段」——进度条走的是**当前分段**，标题区写的 `2 小时 25 分` 是整讲时长，两者不是一回事；鼠标按下即定位，触屏轻点定位、横向拖动实时跟随，纵向滑动仍是滚动页面（不会误改播放位置）
- **播放状态提示**：等数据时卡片内显示「缓冲中…」；加载失败显示「音频加载失败，请检查网络」+「重试」（重试保留失败时的位置，不会退回开头）
- **目录抽屉**：左栏合集、右栏该集讲次，底部分组条（鸟瞰圣经 = 旧约 1–23 / 新约 24–41）；讲次或分组一行一个，当前项高亮
- **播放行为**：同讲内分片自动连播，讲末停住；单分片讲次不显示分段列表
- **断点续听**：记住「哪一讲、第几段、播放到第几秒」，下次进来接着放；刷新/切设备（网页 ↔ APK）各自独立
- **锁屏/耳机控制**：尽力显示讲次名并响应播放/暂停/±15 秒（网页版受浏览器限制，不保证后台播放）
- **没有标注与笔记**：音频没有正文可划线，右栏也就不存在
- 首个合集《鸟瞰圣经（王生台）》41 讲、95 个音频、约 86 小时；音频走阿里云 OSS，不占安装包体积

### 6. 笔记管理（notes）

- 三列：分类树（左）/ 条目列表（中）/ 编辑面板（右；移动端编辑走全屏 push + 返回条）
- **列表能力**：来源 tab（全部/经文/生命读经/书报/听抄）、颜色筛选、全文搜索、分组（按书卷/期）、排序（书卷序/时间倒序）、批量选择/删除（手机端颜色筛选与排序收在工具条第 1 行右侧的「筛选 ▾」弹窗里）
- 点击条目 = 模块内选中进编辑面板（不跳转原文）；编辑面板支持改色 / 改笔记 / 删除 / 定位跳转

### 7. 专题（topic，活力八 · 作业单）

- **入口**：首页「活力八」块 → 作业单页 `#/topic/vitality8`
- **一页 = 作业单的链接聚合**：每周一张任务卡（周次 + 所学章号），卡内按顺序列条目——原文 / 生命读经 ×N（按顺序，带 1/N 序号）/ 指定书报 / 背经 / 注释（读两遍）
- **条目全是跳转，正文不复制**：原文进读经模块该章（注解、串珠、划线都在原位）、生命读经进对应篇、书报进对应章节——点一下就到，不用自己翻卷翻篇
- **未填条目**：书报与背经尚未录入时显示虚化的「待填」行，不可点；作业单在 `scripts/build-topics.py` 里维护（周次 / 章号 / 篇号 / 书报 / 背经），改完重跑脚本即可
- **没有专题内划线/笔记**：作业单页没有正文；划线笔记都在跳转后的各阅读器里，归各自的来源
- **旧版深链兼容**：`#/topic/vitality8/卷/屏` 自动归一到作业单页

## 二、统一导航抽屉（#navDrawer，四阅读模块共用）

- **双栏主从浏览**：按模块渲染层级一/层级二列表（层级一不带序号）
  - 读经：书卷（底部旧约/新约切换，随当前书卷同步）→ 章
  - 生命读经：书卷 → 篇目（懒加载，保留「第N篇」篇目编号）
  - 书报：书（或扁平系列如十二篮的「辑」，底部辑切换仅非扁平系列）→ 篇/章；左栏不带序号与篇数副标，右栏标题剥掉与正文重复的「第N篇/一/（一）」序号
  - 听抄：期 → 篇
- **当前位置高亮同步**：任意跳转（抽屉内/搜索/历史/引用点击）后停靠列 `cur` 高亮跟随
- **Segment**：浏览 | 历史
  - 历史：跨模块阅读历史（上限 50 条、同位置去重置顶、可清空；首页「最近阅读」展示最近 5 条）
- **模块级搜索**：读经搜书卷或「创24」直达该章、生命读经搜全 66 卷篇目、书报跨全部 32 系列（书名/章标题/书号）、听抄搜全期篇目；结果计数为真实总数（超 50 条注明只显示前 50）
- 宽屏（≥1200px）停靠常驻（☰ 收起/展开）；窄屏（≤1199px）退为浮层（遮罩 + 平移，☰ / crumb 点击唤出，Esc 或点遮罩关闭）——停靠列要占 340px，加上研读列 480px 会把正文挤到 901px 时 81px，读不了
- **不承载抽屉的态**：首页、书报二级合集层（层级选择页，均隐藏 ☰）；桌面笔记管理（分类树常驻左栏，隐藏 ☰；移动端仍靠 ☰ 唤出分类树）

## 三、标注与笔记

- **5 色语义划线**（沿用 bible-reader 配色）：选中文本弹浮动工具条，点色即存
- **笔记**：划线可附笔记（模态编辑器，展示标注原文预览）；标注支持改色 / 改笔记 / 删除（分离操作语义）
- **重读**（各阅读器划线汇总标题旁）：当前章/篇存在无笔记的划线时显示「重读」——一键清掉**当前阅读单元自己的**无笔记划线（读经模块只清本章经文，关联生命读经篇目属于别的「篇」不动；生命读经=本篇；书报=当前章；听抄=当前篇），**带笔记的标注原样保留**；确认框明示条数与保留数，删除同步到云端、不可撤销
- **笔记数据五类 + 专题（历史通道）**：经文标注（annotations，数组）、章级笔记、生命读经笔记、书报笔记、听抄笔记、专题屏笔记（kv）。专题屏笔记属旧版专题（1.0.59）的遗留通道，作业单改版后不再产生，旧数据仍参与云同步、仍可在「我的笔记」按「专题」查看
- **复制带出处**：复制标注/正文时附引用出处，方便反馈 bug
- 笔记管理模块承担全部标注的浏览/检索/编辑（见第一节 6）

## 四、经文引用引擎（ref-link）

正文（经文纲目/生命读经/书报/听抄）中的经文引用自动检测并包裹为可点击 `ref-link`：

- **识别形态**：全书式（约一14）、相对式（二五11 / 三9上 / 33）、章节式（三章十九节）、
  列举式（一、二节 / 和 / 与）、范围式（15～17 / 至）、跨章范围（十章二十八节至十二章二十四节）、
  上下半节范围（启一4下～5上）、引导词（参/见/参看）、**相对节范围列举**（「一章七至八节，十二至十四节，
  十六至十七节」——逗号分隔的后续范围沿用前一项的章）、**诗篇「N篇」**（「诗篇一百零七篇二至六节」；
  目录式列举里省略前缀的「七十四篇二至三节」在诗篇语境中同样识别）
- **跨行书卷上下文（carry）**：听抄逐行渲染时段首省略书卷的引用（如「四24」）沿用上一行书卷
- **正文书卷弱上下文**：行文里不带节号的「全名书名」（如「哥林多后书」「希伯来书」）与「书卷+章」
  （如「罗马八章」）虽不成引用，但为其后同一处论述里的引用提供书卷/章号归属——「尤其是哥林多后书，
  多处提到耶稣的治死（四10～13）」「罗马八章所说的万有（28）」都能正确落到林后 4:10-13、罗 8:28；
  旁及别卷不跨句（句号/问号/叹号即失效；分号不算，引文 “”‘’「」『』 里的标点也不计），
  人名简称（约书亚/撒迦利亚等）不建上下文
- **守卫**：章数越界过滤（防「但=but」误判书卷）、节存在性校验（bibleText 未加载时跳过、重渲染后生效）、
  列举不跨章吞并、纯数字右边界防误匹配（1920年/25章）、相对节范围只在「本行同句」有章上下文时才链
  （跨行/跨句宁可少链，不给错链）；跨章范围之后的续节按就近边界归章（「一章一节至二章十一节，十八至二十一节」= 第 2 章；「八章二十七节至九章一节」后的（27）仍属第 8 章）
- **点击**：弹经文卡（逐节展开；半节引用数据未拆分时回退整节）

### 人物链接（person-link，原型：十二篮 + 倪文集）

- 正文里的人名（如「慕迪」「司布真先生」「路德马丁」）自动识别为青绿点线可点，与经文的紫色虚线区分
- **点击弹人物小传**：简介 + 英文名·生卒 + 小传摘录（约 150 字）+ 出处，可「查看完整小传 ›」跳到书报·传记与文集对应章
- **当前覆盖范围**：**十二篮 + 倪柝声文集**正文启用（数据 `data/persons.json` 的 `scope`），其余模块/系列不受影响；词典收录使徒时代之后的历史人物（使徒时代人物名与圣经书卷简称冲突，排除）

## 五、账号与云同步

- **账号密码登录**（主入口）：设置内输入账号名+密码启用同步（账号由管理员开通）；换域名/新设备不再需要授权码。授权码兑换保留为折叠次入口（管理面板 `duoban.xyz/bible-api/admin` 生成/管理）；默认纯本地，未启用时完全离线
- **条目级同步**：标注与四类笔记逐条同步，本地存储格式不变
- **冲突不丢数据**：多端并发编辑自动裁决，败者全文进冲突备份
- **手动同步三件套**（设置内）：立即同步 / 数据对比（本机↔云端）/ 强制推/拉
- 离线可用：断网时改动排队，恢复后自动补传

## 六、阅读体验

- **排版面板（Aa）**：字号 85–200%、行距，桌面居中弹层 / 移动端底部 sheet，按模块独立记忆基准
- **阅读主题**（设置内）：**经典**（默认，靛蓝渐变顶栏）/ **靛蓝**（实色顶栏、中性微影）/ **暖纸**（纸色底+墨色字，经文去卡片化、节间细分隔，暖赭强调）/ **素灰**（中性灰分层、顶栏融入背景、单一强调色）。纯本地偏好不入云同步，刷新不闪变；首页与书报合集块图标随主题在 emoji 与线性图标间切换；标注 5 色语义与排版（Aa）设置各主题通用
- **隐藏注号**开关（设置内）
- **使用帮助**（设置内）：「其他」组的帮助入口——四项功能介绍（起点/阅读/划线笔记/实用技巧，含五色标注语义说明）+「最近更新」；更新弹窗发现新版本时展示同一来源（app.js CHANGELOG）的用户语言「本次更新」，并可跳转帮助查看
- **阅读进度条**：正文滚动实时指示（#textCol 唯一滚动容器）；进度线在顶栏内、视觉仍位于顶边，iOS 顶部不再被进度线取色影响（经典主题白线可见）
- **视图模式**（桌面读经模块）：双页 / 上下 / 全屏
- **移动端单视图**：顶栏 `读经|研读` pill，跨模块进入时高亮自动对齐实际视图
- **分栏拖拽**：桌面研读列宽度可拖（resize-handle）
- **滑动翻页**（移动端）：正文快速横扫切章/篇——向左=下一篇、向右=上一篇（读经切章、生命读经/听抄切篇、书报切本书内章，到边界不动）；与划线标注互不干扰，弹窗/抽屉打开时不响应
- **网址与分享（路由）**：每个位置都有独立网址（首页无 hash；`#/bible/卷/章`、`#/lr/卷/篇`、`#/book/系列/辑/书/章`、`#/morning/期/篇`、`#/notes`、`#/topic/专题`（旧版分屏网址自动归一到此）、合集层 `#/hub`）；链接可直接分享直达，刷新保持位置；翻章/翻篇不留历史记录，后退一步回上一级（换书/换模块/回首页可逐级后退）
- **返回键（APK）**：先关弹窗/抽屉，再逐级后退；首页（无可后退）按返回退出应用；与浏览器后退/前进行为一致

## 七、首页

- **首屏 splash**：启动即显示（含随机经节），启动数据下载期间显示真实字节进度（首次访问慢网约半分钟可感知、可重试；二次访问有缓存秒过）
- 合集块网格：读经/生命读经/活力八（专题）/我的笔记/听抄/听书/倪文集/书报
- **统一检索**：一个搜索框按域分组返回——读经（书卷章，如「创24」）/ 书报（32 系列书名·章标题·书号）/ 生命读经篇目 / **经文全文** / **注解全文** / 我的笔记 / 听抄篇目 / 听书讲次
  - 每组显示真实命中总数，预览前 5 条，可「查看全部」（弹窗内浏览全量，点条目才跳转）
  - 命中词高亮；支持空格分词的 AND 组合（如「属灵书报 重生」）；ASCII 不区分大小写；数字优先按书号匹配，也能命中书名/章标题里的数字
  - 经文与注解全文在内存中检索（启动即加载，零额外下载）；书报正文全文暂不支持
