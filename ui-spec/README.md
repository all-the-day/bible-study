# bible-study UI 规范稿（ui-spec）

> 版本 v1.0 · 2026-11-03 · 基于应用 v1.0.69 实测代码与截图整理
> 事实来源：`style.css`（token 与组件规则）、`docs/FEATURES.md`（行为）、`.ui-review/` 截图（视觉基线）。

## 定位

本文件夹是「读经研读笔记」PWA 的正式 UI 规范专项，供后续改版、新增界面与跨端对齐时使用。它描述**现状的规范化解构**，不是新设计方向；所有数值均取自当前生产代码。

直接双击打开 `ui-spec/index.html`（纯静态、零依赖），左侧导航按分类浏览 SVG 规格稿与 JSX 模板；顶部的过滤框可按名称检索。

## 使用纪律（与 AGENTS.md 一致，此处重申 UI 侧）

1. **token 优先**：新样式一律使用 `:root` 设计 token，禁止新增裸色值 / 裸字号。
2. **经典主题零回归**：classic 主题值 1:1 对应原始实现，是所有改动的对照基线。
3. **五色标注语义不可改**：黄=重要 / 绿=神 / 紫=「我是耶和华」/ 蓝=神所喜爱 / 红=神所恨恶、审判、禁止。
4. **移动断点 900px**：移动规则只放对应媒体查询；顶栏右侧加按钮须同步调整移动端 `.crumb` 的 `right`。
5. **正文缩放白名单**：`--reading-scale` 只作用于阅读正文，不缩放 UI 控件。
6. JSX 文件是**设计文档**，不是可构建代码——本项目为零框架原生 JS；JSX 用于表达组件复用契约，落地时按 `03-components.md` 的 class 映射回 `app.js` 的 DOM 约定。
