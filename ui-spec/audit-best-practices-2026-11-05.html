UI 最佳实践评审

评审对象：ui-spec v1.1.3（8779 分支实装 feat/ui-refactor，19 commits）· 方法：UI-check 五维（图标/排版/色彩/布局/多视口）+ 交互启发式 + WCAG 2.2 AA 口径 · 证据：本会话 14 张实测截图（桌面 1440、移动 CDP 390/659、窄屏 360、设置弹窗、规范稿画廊）

总体结论：这是一套工程素养明显高于平均水准的 UI——对比度体系、图标收敛、感知性能、真重排响应式都做到了"专业产品"级。当前没有阻断性（P0）问题；最值得投入的是三个 P1：窄卡副文案溢出、长书名双截断、动画无减弱偏好适配。三者都是小改动、高感知。

图标图标系统收敛 —— Lucide 官方路径内联（无运行时依赖）、单 stroke 口径、currentColor 跟主题、emoji 从界面图标位清零、品牌定制图形明确保留白名单。
触控44×44 热区显式化 —— 移动端 menuBtn/homeBtn/settingsBtn 显式 44px，高亮态、按压态齐备。
性能感感知性能三件套 —— splash 字节级进度（2.94MB 慢网不再"假死"）、SW 二访秒开、音频错误退避重试且状态落卡不靠 toast。
响应式真重排而非缩放 —— 移动端单列强制重排、翻章移到底部导航、次要操作收进设置菜单；mini 播放条带 safe-area 补偿。
导航深链与历史 —— hash 路由、容器内 replace/跨容器 push 的历史语义、冷启动非法 hash 净化，前进后退全链路可用。
治理层级与状态文档化 —— z-index 链、五状态覆盖（Loading/Empty/Error/Partial/Success）进了规范，组件有 Do/Don't。
阅读正文阅读工程 —— 42rem 限宽、行距/字号/字体三轴用户可调、tabular-nums、五色标注语义四主题恒定。

二、P1 —— 建议本迭代内修

P1-1首页副文案在窄卡溢出换行，块高不齐
证据：.tmp-shots/audit-360-home.png（360 宽：读经块「旧约 + 新约 · 66 卷」两行、首行顶左缘，块比邻块高 20px）· .tmp-shots/m3-home.png（390 已贴左缘）

处置（2026-11-05 同日）：用户洞察采纳——副文案整体移除而非打补丁。统计型（66 卷/41 讲等）对目标读者冗余，释义型下沉模块内；磁贴回归 icon+title 两件套，与书报二级层同构，块高天然对齐。

原建议：① .home-block-sub 加 nowrap+ellipsis；② 360 以下换短文案数据位；③ 块高由 grid 行统一。（已被上述处置取代）

P1-2长书名双截断，信息双损失
证据：用户真机截图（提摩太前书 5章 → 「提摩太… 5…」，书名与章号同时省略）· 复现路径：提摩太前书/帖撒罗尼迦前书等 4 字书名 + 390 窗口

最佳实践：同一行内双 ellipsis 是反模式——用户两端都拿不到完整信息；截断必须有优先级（S2 已定：章号优先于书名），但需要给书名保底。
建议：① bookName 加 min-width: 4ch（至少 2 整字 + 省略号），章号让位；② 更优：移动端书名+章号合成单串「提摩太前书 5章」整体 ellipsis，只留一个截断点；③ 长书名（帖撒罗尼迦/加拉太等）预备 2 字缩写映射（帖前/帖后已有缩写传统）。工作量：1h。

P1-3未尊重 prefers-reduced-motion
证据：style.css 全局过渡（抽屉 margin .25s、toast 上浮 10px/.25s、popup 浮入、progress 动画）；grep 无 prefers-reduced-motion 规则

最佳实践：WCAG 2.3.3（AAA，但 iOS/Android 系统级「减弱动态效果」开关映射此查询）——前庭障碍用户对位移动画敏感。
建议：加一段全局降级：@media (prefers-reduced-motion: reduce){ *{animation-duration:.01ms!important; transition-duration:.01ms!important} }，功能不变、位移归零。工作量：0.5h。

三、P2 —— 排入 v1.1 候选即可

编号发现最佳实践依据与建议维度
P2-1删除标注无撤销破坏性操作应有 Undo（Nielsen #9 错误恢复）。「移除划线」直接落库；建议 toast 附「撤销」按钮 5s 窗口，比确认弹窗更顺。交互
P2-2抽屉方向键导航待补03 自己标注的欠账；书卷/章列表应支持 ↑↓ + Enter（dashboards 级键盘可达）。可访问
P2-3关浮层后焦点去向未定义Esc/✕ 关抽屉/弹窗后焦点应返回触发钮（WCAG 2.4.3）；当前未验证，疑似落在 body。可访问
P2-4空态裸文案无 CTA「还没有任何标注或笔记」没有下一步动作。空态是行动邀请：加「去读经划第一处」按钮（05 已有规范位）。交互
P2-5抽屉 0 结果不回显查询词「无结果」应复述「没有找到“××”」帮助用户确认输入（Nielsen #9/#4）。内容
P2-6抽屉计数未用 tabular-nums「全部 128」等计数变化宽度抖动；01 已把 tabular-nums 定为数字纪律，播放器已遵守。排版
P2-7搜索命中词高亮未验证结果列表应加 <mark> 高亮命中片段（可发现性 #6 识别而非回忆）。交互
P2-8弹窗长列表键盘可达未验证书报篇目弹窗滚动区需 tabindex/焦点管理；移动端无碍，桌面待验。可访问
